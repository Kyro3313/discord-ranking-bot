# Ranking bot
This bot is built with a specific game and rating system in mind, so it may not be useful to you. 

The bot uses discord.js, node.js and sequelize.

## How does it work?
The bot keeps track of matches played via the comand `\record-match`.

Players are rated only using their win rate, different for every type of match (2 players, 3 players and 4 players).
